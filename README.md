# Tamyr — находит корень пробелов в знаниях

**VentureHack 2026 · Трек 2 — EduTech и образование будущего**
Направления трека: персонализированное и адаптивное обучение · оценивание знаний и обратная связь · образовательная аналитика · инструменты для учителей.

> Ученик ошибается в квадратных уравнениях, а причина — в дробях, которые «прошли» в 6 классе.
> Обычный тест покажет «62%, тема: квадратные уравнения». Tamyr покажет **«корень — действия с дробями»** и план, с чего начать.

*Тамыр* (каз.) — корень.

---

## Проблема

- Школьная математика кумулятивна: каждая тема держится на предыдущих. Пробел в базовой теме «всплывает» позже — в теме, которая на ней держится.
- Тесты и пробники ЕНТ дают **балл по теме, где произошла ошибка**, но не говорят, **почему** ученик ошибся. Ученик и репетитор повторяют «квадратные уравнения», хотя чинить нужно дроби или правило знаков.
- Учитель с классом из 25–30 человек физически не может провести индивидуальную диагностику каждого ученика по всем темам с 5 по 9 класс.

## Решение

Веб-приложение из трёх частей:

1. **Адаптивная диагностика.** Начинает с целевой (сложной) темы и при ошибке спускается по графу пререквизитов к базовым темам. Если ученик уверенно решил тему, всё, на чём она держится, засчитывается без вопросов: ученику без пробелов хватает около 9 вопросов, с одним пробелом — около 28.
2. **Карта знаний и план «снизу вверх».** Показывает корневые пробелы, цепочки «ошибка в X → корень в Y», типичные ошибки мышления, найденные по выбранным неверным ответам, и план: правило, пример, разбор *своей* ошибки и 2 проверочные задачи.
3. **Панель учителя.** Корневые пробелы класса, самые частые ошибки мышления, готовые мини-группы для 15-минутного разбора, тепловая карта «ученик × тема», выгрузка в CSV.

## Что внутри (MVP)

| Компонент | Содержание |
|---|---|
| Граф знаний | 17 тем алгебры 5–9 классов (от «Порядка действий» до «Квадратичной функции»), 25 рёбер-пререквизитов |
| Банк заданий | 102 вопроса в формате ЕНТ (6 на тему): в диагностике — до 3 на тему, остальные достаются практике, чтобы ученик не решал уже виденные задания. 134 из 306 неверных вариантов помечены конкретной ошибкой мышления |
| Ошибки мышления | 43 типичные ошибки (например, «складывает числители с числителями, знаменатели со знаменателями»), у каждой есть «домашняя» тема и правило исправления |
| Движок | `js/engine.js`: адаптивный поиск по графу, распространение освоения, маршрутизация по меткам ошибок |
| Хранение | Результаты хранятся на устройстве (`localStorage`). Ученик передаёт результат учителю **кодом** (имя и статусы тем), сервер и сбор персональных данных не нужны |

## Как работает алгоритм

```
стек ← целевые темы
пока стек не пуст:
    тема ← вершина стека; задать вопрос по теме
    2 верных ответа         → ОСВОЕНО
        если без ошибок     → все пререквизиты «освоены (выведено)», вопросов по ним не будет
    2 неверных ответа       → ПРОБЕЛ
        → в стек: непроверенные пререквизиты темы
        → первыми в стек: «домашние» темы ошибок, выданных неверными вариантами
    ответы разделились 1:1  → третий вопрос, решает большинство (такое освоение не распространяется вниз)
корневой пробел = тема-пробел, у которой нет пробелов среди пререквизитов
«под угрозой»   = непроверенные темы, опирающиеся на пробел
```

Решения в движке, которые можно обосновать:
- **Освоение с ошибкой не распространяется на основы.** Угадывание (≈25% при 4 вариантах) иначе «закрывает» целую ветку графа.
- **Корень подтверждается ответами, а не выводом.** При пробеле проверяются даже те пререквизиты, которые раньше были выведены из другой темы.
- **«Не знаю» лучше угадывания.** Кнопка есть в каждом вопросе и считается неверным ответом без метки ошибки.

## Проверка алгоритма (симуляция)

`tests.html` содержит 16 юнит-тестов (граф, банк заданий, правила движка, практика) и симуляцию виртуальных учеников с заранее известными корневыми пробелами. Это проверка алгоритма, а **не** данные реальных учеников.

Модель ученика: знает тему → отвечает верно с вероятностью 92%; не знает → угадывает в 20% случаев, иначе в 70% выбирает «типичную» ошибку. Эту модель составили мы сами, поэтому цифры ниже — оценка сверху, а не обещание.

Движок дорабатывался на наборе «настройка», поэтому основные цифры посчитаны на **отдельном контрольном наборе** — 1000 новых учеников, которых при доработке не видели.

| Набор (цель «Вся алгебра ЕНТ») | Полнота (найдено настоящих корней) | Точность (найденные корни верны) | Карта совпала полностью | Вопросов: без пробелов / 1 корень / 2 корня |
|---|---|---|---|---|
| Настройка (для сравнения) | 79,7% | 73,1% | 77,1% | 8,8 / 28,0 / 30,9 |
| **Контроль** | **79,3%** | **72,4%** | **76,1%** | **9,0 / 28,0 / 30,3** |
| Контроль: угадывание 25% | 71,9% | 65,1% | 69,3% | 9,0 / 26,8 / 29,7 |
| Контроль: 85% верно в знакомых темах | 75,0% | 60,9% | 61,9% | 10,2 / 28,8 / 31,3 |
| Контроль: без шума (проверка логики) | 100% | 100% | 100% | 8,0 / 27,4 / 30,2 |

Цифры контроля почти не отличаются от настройки, значит движок не подогнан под конкретный набор. Но ученику с пробелом нужно около 28 вопросов, это 15–20 минут.

Как повысить точность дальше: использовать все 6 вопросов на тему в спорных случаях, заменить правило «2 из 3» байесовской оценкой освоения, откалибровать вероятности на реальных ответах (см. `docs/validation-plan.md`).

## Похожие решения и чем мы отличаемся

Идея «карты знаний» не новая, и мы этого не скрываем. Вот чем отличаемся от известных решений:

| Решение | Что делает | Чем отличается Tamyr |
|---|---|---|
| **ALEKS** (McGraw Hill) | Адаптивная оценка по теории пространств знаний, платная подписка, программы США | Программа и формат ЕНТ, бесплатно для ученика, работает офлайн без регистрации |
| **Eedi** (Великобритания) | Диагностические вопросы, в которых неверные варианты указывают на ошибку мышления | Та же идея меток ошибок, но мы добавляем спуск по графу к корню в младших классах и план «снизу вверх» |
| **Khan Academy** | Бесплатные курсы и система освоения по темам | Не курс, а короткая диагностика причины: с чего начать повторение |
| **Пробники ЕНТ** | Балл и разбор по темам, где произошла ошибка | Диагноз причины, а не только балл; учителю — корни класса и готовые группы |

Наше отличие — связка «неверный вариант → домашняя тема ошибки → проверка корня» под школьную программу Казахстана, в формате, который работает на любом телефоне без регистрации, с панелью учителя. *Перед защитой проверьте актуальные описания конкурентов на их сайтах.*

## Запуск

Сборка и зависимости не нужны: это чистые HTML/CSS/JS.

- Откройте `index.html` двойным кликом, **или**
- `python -m http.server 8000` → http://localhost:8000
- Тесты: `tests.html`
- Для демонстрации: `#demo` показывает готовую карту ученика с пробелом в дробях, `#demo-quiz` — диагностику в процессе, `#teacher` — панель учителя с демо-классом.

Публикация на GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Что сделано командой и что взято готовым

По п. 5.3 Положения. **Всё, что в репозитории, написано для хакатона**: граф знаний, банк вопросов с метками ошибок, алгоритм диагностики, интерфейс, панель учителя и тесты. Сторонние библиотеки, фреймворки и API не используются. Для ускорения разработки команда пользовалась ИИ-ассистентом и может объяснить каждый модуль.

## Бизнес-модель и внедрение

- **B2C freemium:** бесплатная диагностика; платно — расширенные банки (геометрия, математическая грамотность ЕНТ) и повторная диагностика.
- **B2B для школ и учебных центров:** панель учителя по подписке за класс; репетиторские центры получают инструмент входной диагностики.
- **Масштабирование:** граф и банк — это данные, а не код. Новый предмет (физика, химия) — это новый `data.js` без изменений движка.

## Дорожная карта

1. Пилот в 2–3 классах (9–11 кл.): сравнить найденные корни с оценкой учителя (см. план валидации).
2. Казахский язык интерфейса и заданий.
3. Байесовская модель освоения, калибровка на реальных ответах, 10+ вопросов на тему.
4. Серверная часть для классов (вход по коду класса) с согласием родителей.
5. Геометрия и математическая грамотность ЕНТ.
